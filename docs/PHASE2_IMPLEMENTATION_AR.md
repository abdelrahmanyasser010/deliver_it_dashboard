# تنفيذ التحسينات الاثني عشر — المرحلة الثانية

هذه النسخة تستكمل تطوير الـFrontend Mockup مع الحفاظ على فصل البيانات عن الواجهة وعدم بناء Backend أو Authentication حقيقي.

## 1) البحث الشامل
- إضافة بحث من الـHeader يعمل باستخدام زر `Ctrl/Cmd + K`.
- البحث في الشحنات والعملاء والهواتف والتجار والمناديب.
- الانتقال المباشر إلى الشحنة أو ملف المندوب أو التاجر.

## 2) تخصيص أعمدة الشحنات
- اختيار الأعمدة الظاهرة من نافذة مخصصة.
- حفظ التفضيلات في `localStorage`.
- بقاء رقم الشحنة والتحديد والإجراءات أعمدة أساسية.

## 3) Saved Views
- حفظ البحث والفلاتر والأعمدة الحالية باسم يختاره المستخدم.
- تطبيق View محفوظ بضغطة واحدة.
- حذف Views المحفوظة.
- حفظ آخر 10 Views على الجهاز.

## 4) مركز الاستثناءات
- صفحة جديدة تجمع التأخير، الشحنات بلا مندوب، الفروقات المالية، المرتجعات، حالات خدمة العملاء، وعدم وجود تحديث حديث.
- ترتيب حسب درجة الخطورة.
- فلاتر وبحث وإمكانية استبعاد الحالة بعد التعامل معها.
- فتح الشحنة المرتبطة مباشرة.

## 5) الاستلام بالباركود
- صفحة دفعة استلام مستقلة.
- عدادات المتوقع، الصحيح، الناقص، والمكرر أو غير المتوقع.
- كشف المسح المكرر والكود غير الموجود.
- صوت نجاح أو خطأ عندما يسمح المتصفح.
- التراجع عن آخر مسح ومنع إغلاق الدفعة مع وجود نواقص.

## 6) تطوير التقارير
- مؤشرات مقارنة بالفترة السابقة.
- تعريف للمؤشرات عبر أيقونة المعلومات.
- Drill-down إلى الشحنات أو المندوب أو المحافظة.
- إصلاح تسمية تقرير المحافظات.

## 7) المحاسبة والتسويات
- شريط مطابقة بين المحصل والمورد والنقدية مع المناديب والفروقات.
- فتح الاستثناءات المالية مباشرة.
- ربط حركات كشف الحساب بالشحنات.
- تطوير التسويات إلى دورة: معلقة، معتمدة، مدفوعة.
- عرض المتوقع والخصومات والصافي والفرق وسجل مراحل التسوية.
- فلاتر وتصدير واعتماد جماعي وتسجيل الدفع.

## 8) ملف المندوب
- ملف تفصيلي من جدول المناديب أو البحث الشامل.
- الحمولة والسعة، نسبة النجاح، العهدة، نهاية الوردية وآخر موقع.
- تنبيهات العهدة المرتفعة، الموقع القديم، انخفاض النجاح أو امتلاء السعة.

## 9) ملف التاجر
- ملف بتبويبات: نظرة عامة، الفروع والاستلام، الأسعار، الأداء.
- عرض دورة التسوية والمستحقات ونسبة النجاح والمرتجعات.
- نموذج فروع وعناوين استلام متعددة وأسعار حسب النطاق.

## 10) الشات والإشعارات
- تصنيف المحادثات إلى تجار، مناديب، وداخلية.
- بحث وفلتر غير المقروء وتثبيت المحادثة.
- إرسال رسائل فعلية داخل الـState، ملاحظات داخلية، موقع ومرفق تجريبي.
- ربط المحادثة بشحنة وعرض سياقها بجانب الشات.
- إغلاق وإعادة فتح المحادثة ومحاكاة تحويلها لموظف.
- إشعارات قابلة للقراءة والحل مع انتقال مباشر للمهمة.

## 11) واجهات حسب الدور
- تبديل Demo بين الإدارة، التشغيل، المحاسبة، وخدمة العملاء.
- تغيير القائمة الجانبية والصفحة الرئيسية حسب الدور.
- العودة للرئيسية عند تغيير الدور لمنع بقاء المستخدم في صفحة غير مناسبة.
- هذه محاكاة Frontend وليست صلاحيات أمان حقيقية.

## 12) Design System
- إضافة مكونات مشتركة: `MetricCard`, `SectionHeader`, `StatusBadge`, `FilterChip`, `Modal`, `ToastHost`.
- نظام Toast موحد على مستوى التطبيق.
- استخدام المكونات المشتركة في الصفحات الجديدة وتحسين الاتساق البصري.

## حدود النسخة الحالية
- كل العمليات تعدل State محلي أو `localStorage` ولا تحفظ في قاعدة بيانات.
- الصلاحيات المعروضة حسب الدور ليست Authorization حقيقيًا.
- دفع التسويات والمرفقات والموقع وإرسال التنبيهات عمليات Mockup.
- الباركود يستخدم الإدخال كقارئ Keyboard Wedge ولا يتصل بجهاز Hardware API مخصص.
- لم تتم إضافة Vitest أو Playwright لأن المطلوب كان تنفيذ التحسينات الاثني عشر، والاختبارات كانت بندًا منفصلًا في المراجعة السابقة.

## التحقق
- `npm run lint` ناجح.
- `npm run build` ناجح.
- تم تشغيل Vite Preview والتحقق من استجابة المسارات الأساسية والجديدة بـHTTP 200.
- تعذر إنتاج Screenshots آلية بسبب قيود Chromium Headless داخل بيئة التنفيذ، وليس بسبب خطأ Build.
